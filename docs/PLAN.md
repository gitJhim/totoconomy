# Foundation implementation plan

1. Implement checked integer accounting, validated scenarios, atomic trades/work/production, and the exact six-household cycle. Prove intermediate balances.
2. Extend the same engine with reservations/delays, a 24-household/two-product town, restricted observations, deterministic decisions, and bounded firm pricing.
3. Stream economic facts, decision evidence, metrics and display snapshots; implement complete-boundary checkpoints, resume, noop/public-board branches, and independent reconciliation.
4. Finish strict CLI and incompatible-input checks. Execute all 18 acceptance cases in Debug, Release and sanitizer builds. Measure actual Release workloads.
5. Audit the goal requirement by requirement; document formats, model, reproducibility, evidence, limitations and the next four stages.
